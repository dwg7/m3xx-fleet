# m3xx フリート状態ダッシュボード

JICA国家測量研修用Raspberry Piフリート(`m3xx`)の状態を表示するOpen MCTダッシュボードです。

https://dwg7.github.io/m3xx-fleet/ で公開しています。

## このリポジトリについて

- 表示しているのは**匿名化・集約済み**の情報のみです(ホスト名・役割ラベル・健全性
  ステータス・OS/カーネルバージョン・最終確認時刻)。IPアドレス・MACアドレス等の
  LANトポロジー情報は含みません。
- `data/fleet-status.json` は定期的に更新されます。収集に失敗した場合は
  `freshness_note` にその旨と最終成功時刻が明示されます。
- 運用の詳細・意思決定の経緯は非公開リポジトリ `dwg7/m3xx-fleet-ops` で管理しています。
  このリポジトリはダッシュボード表示専用です。
